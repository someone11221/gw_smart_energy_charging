# ⚡ Smart Battery Charging Controller

Inteligentní řízení nabíjení domácí baterie pro Home Assistant s optimalizací na české spotové ceny elektřiny.

## Hlavní funkce
- Cenová optimalizace (OTE/Nanogreen)
- Distribuční tarify ČR (EG.D, ČEZ, PRE)
- HDO signál v reálném čase
- Adaptivní predikce spotřeby
- Statistiky nákladů s odhadem úspory
- Nouzový fallback při výpadku dat
- Vestavěný debug systém
- Lovelace karta + webový dashboard
