# Smart Battery Charging Controller v3.0.1

⚡ **Inteligentní řízení nabíjení baterie s predikcí cenových peaků**

## ✨ Nové funkce v 3.0.1

### 🧠 Chytrá predikce
- Automatická detekce cenových špiček 48h dopředu
- Preventivní nabíjení před peaky
- Opportunistické full-charging při ultra-nízkých cenách
- 4 úrovně priority nabíjení

### 🎨 Moderní UI
- Krásný dashboard s Chart.js grafy
- Real-time monitoring SOC a cen
- Barevné vizualizace nabíjecích slotů
- Responzivní design

### 🏗️ Modulární architektura
- Snadné přidávání nových price providers
- Podpora různých baterií (GoodWe, Tesla, Huawei)
- Rozšiřitelné charging strategies

## 📱 Dashboard

Přístup: `http://homeassistant.local:8123/api/gw_smart_charging/dashboard`

## 🚀 Quick Start

1. Nainstalujte přes HACS
2. Restartujte Home Assistant
3. Přidejte integraci: Nastavení → Zařízení a služby
4. Nakonfigurujte price provider a baterii
5. Otevřete dashboard a užívejte si úspory!
